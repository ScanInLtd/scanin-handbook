Assignment:
1. **Review (read first, report before changing much).** Current state, what works, and the known limitations (`KNOWN_LIMITATIONS.md`, `PROGRESS_*.md`).
2. **Auto reset / boot.** Use esptool's automatic reset by default: `--before default_reset --after hard_reset`, and for ESP32-S3 native USB `--before usb_reset` where applicable.

4. **Packaging.** A single installer or a self-contained zip (`dotnet publish -r win-x64 --self-contained -p:PublishSingleFile=true`), with esptool bundled. Upload it to a stable location (e.g. Google Drive / Storage) and give Hillel a link plus 5-line install steps in Hebrew for Nathan / Lidor.

Rules: no secrets in git or in the package. Don't publish the link before Hillel approves the security change.
